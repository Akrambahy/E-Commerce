# E-Commerce

A simple E-Commerce project built with **C# and .NET**.

## About

This project is a learning project focused on building an E-Commerce system while applying Learn C# Basics And core programming and software engineering concepts.

## Features

* Product management
* Product inventory
* Shopping cart
* Order management
* Basic E-Commerce operations

## Technologies

* C#
* .NET


## Getting Started

### Clone the repository

```bash
git clone https://github.com/Akrambahy/E-Commerce.git
cd E-Commerce
```

### Run the project

```bash
dotnet run
```

## Purpose

This project is part of my journey in learning **C#, .NET, OOP, and Backend Development**.
